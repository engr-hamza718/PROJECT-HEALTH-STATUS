What this tool does

Schedule Pulse runs a set of structural checks against a Primavera P6 schedule, inspired by the U.S. Defense Contract Management Agency's 14-Point Assessment — an industry-standard set of tests for network logic, float, duration, and constraint health. It is a diagnostic aid, not a certification: it flags patterns worth a planner's attention, it doesn't replace judgment about the specific project.

The checks

  1. Missing Logic — detail activities with no predecessor and/or no successor.
  2. Negative Lag (Leads) — relationships using a negative lag.
  3. Positive Lag — relationships using a positive lag.
  4. Finish-to-Start Ratio — share of relationships that are FS (target ≥ 90%).
  5. Hard Constraints — mandatory / must-start / must-finish constraints.
  6. High Float — total float over 44 working days.
  7. Negative Float — activities forecasting past a required/constrained date.
  8. High Duration — detail activities planned over 44 working days.
  9. Stale Forecast Dates — incomplete activities forecast before the data date.
  10. Unresourced Activities — detail activities with no resource or cost, when resource data exists in the file.
  11. Duplicate Activity IDs — activity codes appearing more than once.
  12. Critical Path to Finish — whether the driving path reaches a finish milestone.
  13. % Complete vs Status — % complete inconsistent with activity status.
  14. WBS Coverage — every detail activity sits under a real WBS node.

How the score is calculated

Each applicable check contributes equally to the 100-point score. A passing check earns full credit. A failing check earns partial credit that shrinks the further its value sits past the threshold, down to zero once it's 25 percentage points over. Checks that don't apply to the loaded file (for example, resourcing checks on a schedule with no resource data) are excluded from the denominator rather than penalized.

This weighting is a reasonable default, not a contractual standard — if your organization uses different thresholds or weights for its own QA/QC gate, treat this score as a starting conversation, not a pass/fail gate on its own.

Resource histogram & cost S-curve

When the loaded file includes resource or cost assignments per activity, planned units and cost are spread evenly across each activity's planned duration and bucketed by week to build the histogram and cumulative S-curve. This is a simplified linear spread, not a true resource-leveled profile from P6 — useful for a quick shape check, not for detailed resource planning.

Privacy

All parsing, scoring, and charting happens in your browser. No file is ever sent to a server or stored anywhere. Refreshing the page clears everything.
